## Simple Bot Agent Requirements
### Objectives
1. Define state structure with a list of HumanMessage objects.
2.
    a. (If you have OPEN_API_KEY) Initialize a GPT-4o model using LangChain's ChatOpenAI
    b. (If you don't have OPEN_API_KEY) Initialize a gemma-3 model using LangChain's OLLAMA model
3. Sending and handling different types of messages
4. Building and compiling the graph of the Agent
